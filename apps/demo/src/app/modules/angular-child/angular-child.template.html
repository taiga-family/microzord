Standalone approach

If your application is built with standalone components, you can skip root modules entirely: pass your root component to the createStandaloneApp helper instead of converting an NgModule with createApp .

The helper accepts the root component, its selector and optional providers which are used during bootstrapApplication() : a router, change detection configuration, anything else your app needs. From the host point of view both helpers are interchangeable, so a host can register module-based and standalone children side by side.

Zoneless change detection

A standalone child can work without zone.js at all: add provideExperimentalZonelessChangeDetection() to the providers and drop the zone.js polyfill from the child build.

Such a child schedules its own change detection via ApplicationRef , so it coexists with a host that still uses zone.js.

Zoneless change detection reacts to signals, markForCheck() and scheduled ApplicationRef.tick() calls. Plain asynchronous state updates won't re-render the view unless you touch one of these.

Lazy modules
