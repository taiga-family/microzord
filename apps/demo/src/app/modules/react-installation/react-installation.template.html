microzord has an ideomatic React wrapper which turns any React element into a child application.

Package installation

Install the core package if you do not have it yet:

npm i @microzord/core

Install React package for ideomatic working with React (React 18 and later are supported):

npm i @microzord/react

What is next

The React package covers the child side: follow React as a child to prepare your application to be inserted in another app.

To render other applications inside a React app, use the core package API directly.
