Here you can read how to setup your application to be inserted into another app.

A React application can be hosted by any microzord host, for example an Angular one .

Installation

See React package installation

Child application entry point

You should create file with an application and expose it via module federation. Microzord provides createApp helper which wraps a React element into a microzord child application.

On bootstrap the element is rendered with react-dom/client into the container provided by the host, on destroy it is unmounted. Lifecycle hooks ( bootstrapped , destroyed ) are emitted as for children of other frameworks.
